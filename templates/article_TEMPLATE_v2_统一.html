一组"漂亮"的回测曲线，我先泼盆冷水

很多人回测一跑，年化 30%、回撤 5%，高兴得不行，觉得自己离财富自由就差一个"实盘开关"。可我把同一套数据反复交叉比对后，结论有点扎心：你那根漂亮的曲线，很可能建立在假数据上。

同一只票，A 数据源的历史最高价被"除权缺口"吞掉一大截，B 数据源却没处理——你用 A 跑出来的趋势策略，在 B 上直接变成另一套结果。同样的策略逻辑，收益率能差出一个量级。问题不在策略，在源头。

你那根漂亮曲线，可能建立在假数据上

最常被忽略的是"下载即用，不做来源交叉"。单源数据天生有盲区——停复牌、除权、退市、复牌首日异常，错一次，回测结论就整体偏掉，你还以为是自己策略不行。

更隐蔽的是"把未复权价当真实价算收益"。分红送转后价格出现断层，用未复权价算收益率，能把"小赚"算成"翻倍"、把"小亏"算成"腰斩"。数字越漂亮，越要警惕。

核心真相：数据的"可信度"不是下载下来就默认 100%，而是靠交叉比对逼出来的。多问一个来源，就少踩一个坑。

怎么判断你的数据到底能不能信

说白了就一句话：用至少两个独立来源采集同一标的同一字段，对不上的地方就是风险点。好比问三个人同一件事，三个人说法一致才可信；一个人说的，先打个问号。

关键字段必须双源对照。价格、股本、除权除息这类直接影响收益的核心字段，✅ 至少两个来源比对；❌ 单一来源直接入库就当真相，等于把命交给一个可能出错的人。

复权口径先统一再算收益。✅ 用同一套前复权口径算所有历史收益，保证可比；❌ 一部分前复权、一部分未复权混着算，结果必然失真，连"赚还是亏"都说不清。

对不上的数据，宁可弃用。✅ 两个来源差异超可接受范围且无法解释时，标灰弃用整段；❌ 为了"看起来完整"强行插值补数，补出来的数字比缺数据更危险。

同一只票，三个数据源能差出多少

下面用一组模拟数演示方法（非真实策略参数，仅用于把逻辑讲清楚）：取某标的历史最高价，新浪全 A 报 10.2、腾讯实时报 10.1、mootdx 历史报 8.7——前三者在 1% 内吻合，但 mootdx 因未处理一次 10 送 2 的除权，直接低了 14.7%。

📊 最高价偏差：前两个源差 1%，第三个源差 14.7%，差出一个量级。

📊 长期收益影响：用 8.7 算的趋势策略，回测年化比用 10.2 的低约 9 个百分点，结论直接反转。

📊 弃用比例：按"差异不可解释即弃用"，这类标的约占抽样 2–3 成，宁可少做也不带病入场。

📌 数据来源：演示数字为模拟序列（参数占位，非真实策略）；多源采集口径参考交易所公开披露与主流数据源文档核对。本文不构成任何投资建议。

这套方法，也不是万能的

两个"独立源"也可能同源转引，交叉比对会给出虚假一致；复权口径本身有争议，前/后复权选择会长期影响收益观，没有绝对标准；分钟级数据的多源对齐成本极高，小资金不划算。校验提升可信度，但消灭不了所有误差——只用亏得起的闲钱试错，别把"经过校验"当成"稳赚"的背书。

船长的话：我做量化最贵的教训，不是某次交易亏了多少，而是回测"赚钱"了半年，最后发现源头数据漏了一段停牌。那一刻我明白：策略可以慢慢调，数据一旦假，上面盖多少层逻辑都是沙上筑塔。宁可慢，不可假——这是量化里最朴素也最容易被忽略的一条。

从今天起，多问一个来源

不会写代码也能用：同一个关键数字，至少找两个地方核对一遍；算历史收益一律用前复权价；对不上的标的，先别碰，宁可错过也不带病交易。校验是为了"敢信"，不是"敢重仓"，先小范围验证。

def collect(code):

# 拿到 raw 后交给下方的差异检测，而不是直接入库

Python · 差异检测：对不上即标灰（示意版）

# 多源一致性检查：差异超阈值且无法解释 → 标灰弃用
# ⚠️ 差异阈值为示意占位，非真实参数
TOLERANCE = 占位_可接受相对偏差

def flag_mismatch(df):
    base = df.median(axis=1)  # 以中位数作基准
    for s in df.columns:
        rel = (df[s] - base).abs() / base.abs().replace(0, float("nan"))
        df[f"flag_{s}"] = rel > TOLERANCE  # True = 异常
    return df

flagged = flag_mismatch(df)
bad_cols = [c for c in flagged.columns if c.startswith("flag_")]
print("异常字段占比:", flagged[bad_cols].mean().round(3).to_dict())
