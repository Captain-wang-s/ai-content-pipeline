# 01-framework-shrink-refine

- Type: framework
- Style: flat-vector / sci-fi
- Palette: blue (#4776e6 主色, 深蓝背景)
- Aspect: 16:9

## ZONES
- 左侧：一片密集的小圆点/方块（代表 5000 只股票的噪点海洋），颜色偏灰蓝、低对比。
- 中部：一个发光的漏斗/滤波器结构，把左侧噪点吸入，过滤掉大部分。
- 右侧：漏斗出口只留下少数几颗明亮聚焦的晶体/星点（代表精选后的 Top30），高亮、锐利。

- 漏斗光：#4cc9f0 / #4895ef 青蓝发光
- 精选晶体：#ffd60a / #fff 暖白高亮（仅右侧少量）
