# 中段插画 Prompt 模板 v3（贴合文章 + 精致手绘）

> 目的：让 AI 画的图「讲清楚文章的某一段逻辑」，不是「画一幅好看但无关的装饰画」。
> 用法：每篇 2 张，每张从文章里挑 1 个段落核心概念，填完本模板后整段丢给 ImageGen。
> v3 升级：吸收「精准复刻式中文 prompt」写法——**风格前置锁死 + 空间顺序描述 + 统一元素语言 + 负面词独立**。
> ⚠️ 船长Talk 铁律：插画内**零文字**（避免乱码 + 合规），文字需求全部转成「图形表达」，caption 放 HTML。

---

## 第一步：先写「一句话概念」——图的灵魂

从文章中挑一个**核心论点/机制/对比**，用一句话说清它是什么：

```
概念：________________________（如：过拟合=一条漂亮曲线背后是随机噪声）
文章对应段：__________________（h2 标题或段落内容）
关系类型：____________________（对比 / 流程 / 比例 / 结构 / 因果 / 时间线，选一个）
```

> ⚠️ 关系类型决定构图骨架（对应下方 §模板 ② 的板块结构）：
> - **对比** → 左右分栏（左=问题/旧模式，右=方案/新模式）
> - **流程** → 左→右 箭头串 / 闭环循环
> - **比例** → 饼图 / 堆叠条 / 漏斗
> - **结构** → 分层框架 / 嵌套圆角矩形
> - **因果** → 输入端 + 中间机制 + 输出端

---

## 第二步：填模板（6 段，顺序固定，直接拼装）

### ① 固定风格段（放最前面锁画风，权重最高）

> 风格段全篇统一、基本不改，只换配色里的主题色。

```
极简手绘扁平信息插画，治愈系简笔画风格，圆润均匀的黑色细轮廓线，
低饱和度莫兰迪马卡龙配色，米白色做旧糙纸质感背景（#FDF8F0 满铺四边），
平面化设计，无复杂光影，整体画面干净柔和。
主强调色：{主题色，如 绿#4CAF50}（只用于核心元素，其余用低饱和马卡龙辅色）。
```

### ② 构图框架段（先定整体，再讲细节）

```
画面采用{左右对比分栏 / 从左到右流程 / 中心闭环循环 / 上下分层}结构，
{顶部/左侧/右侧/底部}各板块间用{黑色粗箭头 / 虚线连接 / 曲线路径}连接，
箭头方向表达「{文章逻辑，如：从混乱到收敛}」。
所有内容置于画面中央偏下，四周留白充足，底部 25% 高度留空（水印区，内容不得贴底）。
```

### ③ 左侧/上游板块段（问题 / 困境 / 旧模式）

```
左侧{暖珊瑚粉 #FFD4D4}圆角矩形区域：
{具体场景描述，含简笔小白人状态 + 核心物件 + 环境细节}；
区域底部有{数量}个圆角{标签色}标签，用简笔图标替代文字表达
「{标签1含义}」「{标签2含义}」「{标签3含义}」。
```

### ④ 右侧/下游板块段（方案 / 结果 / 新模式）

```
右侧{薄荷绿 #D4FFE0}圆角矩形区域：
{具体场景描述，含核心图形、循环结构、图标节点等}；
节点用{白色圆形+黑色轮廓}承载简笔图标，表达「{节点1}→{节点2}→{节点3}→{节点4}」的递进。
```

### ⑤ 收尾质感段（强调质感 + 版式整洁）

```
信息图排版，边缘清晰，手绘质感，高清画质，整洁有序，
所有元素风格完全一致（简笔图标、圆角矩形、黑色细轮廓线统一）。
```

### ⑥ 负面 Prompt（独立一段，稳定画风避坑）

```
写实，3D渲染，厚涂，厚重阴影，高饱和度刺眼色彩，杂乱背景，
人物写实五官，模糊扭曲，错别字，乱码，复杂纹理，多余装饰，
渐变效果，立体感，照片质感，真人形象，任何文字、字母、数字。
```

## 第三步：文字 → 图形 转换对照表（船长Talk 零文字铁律）

| 你想写的文字 | 转成什么图形 |
|-------------|-------------|
| 「目标太大」「系统太多」「没有收尾」 | 3 个圆角标签，各配一个简笔图标（超大地图/叠加方块/断尾箭头） |
| 「能开始→能上线」 | 4 节点闭环，每个节点一个图标（旗子/齿轮/对勾/火箭） |
| 「先做完整，再做复杂」 | 底部总结区：一个小完整方块 + 箭头指向 + 大复杂迷宫，迷宫画小 |
| 「缩小范围」 | 箭头上画一个内收的漏斗符号（不写字） |
| 「-4.7% vs -11.3%」 | 两根迷你柱状条，一矮一高，矮的绿色高的粉色 |
| 「70/30 样本外」 | 饼图切一块，大块蓝色小块粉色，不标数字 |
| 「正收益 / 负收益」 | 上升绿箭头 vs 下降红箭头（小图标） |

> 原则：图形能表达的关系，绝不写字。数字用比例/长短/大小暗示。

## 拼装示例（「过拟合陷阱」第一张，v3 版）

```
极简手绘扁平信息插画，治愈系简笔画风格，圆润均匀的黑色细轮廓线，
低饱和度莫兰迪马卡龙配色，米白色做旧糙纸质感背景（#FDF8F0 满铺四边），
平面化设计，无复杂光影，整体画面干净柔和。主强调色：绿 #4CAF50。

画面采用左右对比分栏结构，左侧板块与右侧板块之间无文字连接，
仅用一条黑色曲线贯穿全幅——曲线从左上方一路平滑上扬到右上方，
看似完美，实际上逐点穿过散落在画面各处的粉色与蓝色小圆点。
左侧板块：一块手绘网格纸，网格上是那条干净的绿色平滑曲线，
曲线是全场最粗最深的元素（视觉核心）。
右侧板块：一把简笔放大镜悬停在圆点密集区上方，暗示「看出真相」。
画面底部 25% 高度留空，所有内容置于中央偏上，四周留白充足。

信息图排版，边缘清晰，手绘质感，高清画质，整洁有序，
简笔图标、黑色细轮廓线全图风格统一。

写实，3D渲染，厚涂，厚重阴影，高饱和度刺眼色彩，杂乱背景，
人物写实五官，模糊扭曲，错别字，乱码，复杂纹理，多余装饰，
渐变效果，立体感，照片质感，真人形象，任何文字、字母、数字。
```

## 对照检查表（生成前过一遍）

- [ ] 一句话概念写了吗？（图要能「一句话讲清文章某段」）
- [ ] 风格段放最前面，主题色标了吗？
- [ ] 构图框架段定了结构（左右对比/流程/闭环/分层）？
- [ ] 每个板块写了「画什么 + 代表文章什么」，不准只写画什么？
- [ ] 想写的文字全部转成图形了？（查对照表）
- [ ] 底部 25% 留空、四周不贴边？（否则裁切 FAIL）
- [ ] 负面词 6 项齐了吗？（写实/3D/厚涂/高饱和/乱码/文字）
- [ ] 生成后 crop_illustration_v7.py 四边 ≥3% 才可用，FAIL 就加 `--pad 200`，再不行 `--pad 400`

## 常见失败模式 & 对策

| 失败表现 | 根因 | 对策 |
|----------|------|------|
| 内容贴边、裁切 FAIL | 底部留空没写 | 补「底部 25% 高度留空」+ `--pad 200/400` |
| 图里出现中文/字母 | 负面词没写死 | 末尾必带「任何文字、字母、数字」 |
| 画成商业插画/写实风 | 风格段被挤到后面 | 风格段必须放最前面，负面词独立收尾 |
| 跟文章没关系 | 概念句没提炼 | 先写一句话概念，再填板块 |
| 主次不清 | 没标视觉核心 | 明确「XX 是全场最粗最深的元素」 |
| 颜色突兀 | 色板太自由 | 只给 1 主题色 + 低饱和马卡龙辅色，禁高饱和 |
| 元素风格不统一 | 元素语言不统一 | 全程用「简笔小白人/圆角矩形/简笔图标」固定词 |

## 与 SOP §8.4.5 的关系

本模板是 §8.4.5 手绘科普风的操作化补充：§8.4.5 规定「风格铁律」，本模板规定「如何让图贴合文章内容」。两者缺一不可——只讲风格会得到精致但无关的图，只讲内容会得到贴题但粗糙的图。
