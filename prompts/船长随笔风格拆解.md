## 二、两种语域（写前先选）

### A. 航海日记诗体
适用：年终总结、个人经历、情感复盘、里程碑（30岁/牙套/离职）
特征：一句一行、多数句子不带标点、排比堆叠、首尾呼应

> 示例：「我试着捧着鲜花穿过人群／我试着在街头大胆点歌唱歌／我试着和别人打招呼」（《23年总结》九连排比）

### B. 公众号口语体
适用：观点输出、热点评论、干货+情绪
特征：长段落、有连接词、故事驱动、💬 互动

> 示例：「我跟他说，这次分手她没提任何条件……」（《失恋后别自我感动》）

**本篇文章：走 A 为主、B 为辅（B 用于小标题下的说理段）。**

## 三、固定元素（缺一不可）

1. **开场两句**（航海日记固定句，多篇复用）：
```
学习是为了不落后，
整理则是为了不忘记。
```
2. **引号诗块**：把配文/感慨放进 `" "` 独立成块（《25岁牙套》《30岁在路上》）
3. **数字自述**：把人生压缩成数字，最出效果
   - 《23年总结》：「[10115,1308,678,481,152]」= 存在天数/毕业天数/在职天数/戴牙套天数/分手天数
4. **引号式标签自述**：「30岁、未婚、职场5年、失业、在路上」
5. **小标题**：两种
   - 编号式：`01 焦虑与迷茫` `02 挫败与收获`（《从业故事》）
   - 冒号金句式：`一、欲望的囚徒：在廉价的"温暖"里，冻僵余生`（《三十而砺》）
6. **结尾**：`END` + 签名块
```
END
微信号｜Captain_Data
微信昵称｜ 船长Talk
```
   或（口语体）：`— 船长Talk —` / `数据分析 + 职场真相 + 投资洞察` / `欢迎公众号后台回复"进群"一起交流`
7. **互动**（口语体必带）：`💬 你有过"认命"的时刻吗？评论区扣数字：1是18岁 / 2是25岁 / 3是30岁`

## 四、语言特征

| 特征 | 说明 | 例句 |
|------|------|------|
| 排比 | 3~9 连排，最出情绪 | 「我试着捧着鲜花穿过人群／我试着在街头大胆点歌唱歌」 |
| 首尾呼应 | 开头那首诗结尾原样再现 | 《牙套》：开头「有些春天／早一天播种」→ 结尾再现 |
| 自嘲 | 用段子化解沉重 | 「回家继承爸妈留下的一万头牛、两万头羊和三千亩的QQ农场」 |
| 金句收束 | 每节尾或全文尾 | 「认命不是躺平，是把精力从'不可能'收回到'可能'」 |
| 具体数字 | 精确到天/次数/金额 | 「投出300+份简历」「面试了20多场」「2万8存款单」「1153天」 |
| 引用块 | 独立成行的警句 | 「成功绝非易事，失败绝非偶然」 |
| 疑问句拉读者 | 直接问 | 「你知道世界上最远的距离是什么吗？」 |

### 「三次认命」母题（可复用骨架）
- 18岁，我认了自己不是天才。→ 选了数据分析，靠手艺吃饭
- 25岁，我认了自己平庸匮乏。→ 螺丝钉，跳槽互联网从零学业务
- 30岁，我认了自己贫穷一生。→ 研究Web3，赌下一个十年
- 收束：**认命不是躺平。试探，是认命之后唯一还能做的事。**

## 五、禁忌（对照检查）

- ❌ 一词一行（碎断），读起来"不通顺"——**分行必须是一个完整分句**
- ❌ markdown bullet 列表、**加粗小标题**堆砌（会变成"报告体"）
- ❌ 文末「数据来源/合规自检」表格（随笔不需要，数据写成自然句）
- ❌ 书面连接词堆砌（"也就是说""恰恰相反"）
- ❌ 编造数据（引用必须真实，BLS 等外部数据注明来源）

## 五点五、⚠️ 去重铁律：模仿语感，禁止搬运原句（2026-09-12 船长明确否决）

**船长原话：「你这篇文章用了好多我以前写的词 不好」。**

写随笔时，只允许从旧文里取 **经历、事实、数字、事件**，
**严禁**把船长的原句、金句、招牌句式、自创比喻直接搬进新文——那是复读，不是写作。

**已确认的禁用清单（这些是他写过的，不能再用）：**

| 类型 | 原句（禁搬） | 正确做法 |
|---|---|---|
| 固定开场 | 学习是为了不落后，整理则是为了不忘记。 | 直接进场景，或自写新开场 |
| 自创诗块 | 有些春天，早一天播种，就早一万次微笑。/ 有些坑，早一天踩，就早一万次清醒（仿写也算搬运） | 换一个全新意象，或干脆不写诗 |
| 金句 | 世界上最远的距离，不是生与死，是"知道，但办不到"。 | 用自己的话重述成普通句 |
| 母题句 | 认命不是躺平 / 试探，是认命之后唯一还能做的事 / 接受自己大概率会输，但依然下注 | 只可引用其"内核"，须全新措辞 |
| 收尾句 | 我是船长，接受平庸，但不甘心平庸。 | 另想一句全新的收尾 |
| 自创比喻 | 旧地图 / 新大陆 / 业务与数据之间的绝缘体 / 海量名词仿佛有结界 / 无根之木 / 哑火 | 换比喻，或写成直白叙述 |
| 自述标签 | "30岁、未婚、职场5年、失业、在路上" | 不要复用这个句式 |
| 数字自述 | [10115,1308,678,481,152] | 不要复用这个噱头 |
| 具体措辞 | 夜以继日，终于付之东流 / 那几个可怜的工具 / 结结巴巴的逻辑 / 行情下跌、HC收缩、你还是另谋高就吧 | 转写成自己的叙述 |

**可安全复用（属于事实/格式，非"词"）：**

- 真实事件与细节：三百多份简历、二十多场面试、入职不到一周出差、拔十颗牙、1153 天、被裁那场远程会议、2023 年整年没主动学习、第一次在职场发火
- 格式：`## 一/二/三` 编号分节、`END` + 签名块、短行换行节奏、结尾无附录
- 招呼语：「大家好，我是船长。」

**自检方法**：定稿后逐句问自己——"这句话是不是在旧文里出现过？"
凡是"似曾相识"的句子，一律重写。判断标准是**内容可以旧，文字必须新**。
