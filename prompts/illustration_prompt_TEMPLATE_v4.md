# 中段插画 Prompt 模板 v4（贴合文章 + 结构化信息图）

> 目的：让 AI 画的图「讲清楚文章的某一段逻辑」，不是「画一幅好看但无关的装饰画」。
> 用法：每篇 2 张，每张从文章里挑 1 个段落核心概念，填完本模板后整段丢给 ImageGen。
> v4 升级：新增「结构化功能卡片 / 选择对比卡」风格——参考 Codex 4 入口图，用**编号卡片 + 图标 + 标签 + bullets + 底部决策流**表达「按场景选择」。
> ⚠️ 船长Talk 铁律：插画内**零文字**（避免乱码 + 合规），文字需求全部转成「图形表达」，caption 放 HTML。

---

## 第一步：先写「一句话概念」——图的灵魂

从文章中挑一个**核心论点/机制/对比/使用入口**，用一句话说清它是什么：

```
概念：________________________（如：按场景选最适合自己的数据分析入口）
文章对应段：__________________（h2 标题或段落内容）
关系类型：____________________（对比 / 流程 / 比例 / 结构 / 因果 / 时间线 / 功能入口选择，选一个）
```

> ⚠️ 关系类型决定构图骨架（对应下方 §模板 ② 的板块结构）：
> - **对比** → 左右分栏（左=问题/旧模式，右=方案/新模式）
> - **流程** → 左→右 箭头串 / 闭环循环
> - **比例** → 饼图 / 堆叠条 / 漏斗
> - **结构** → 分层框架 / 嵌套圆角矩形
> - **因果** → 输入端 + 中间机制 + 输出端
> - **功能入口选择** → 横向/纵向编号卡片矩阵 + 底部决策流

## 第二步：填模板（6 段，顺序固定，直接拼装）

### ① 固定风格段（放最前面锁画风，权重最高）

> 风格段全篇统一、基本不改，只换配色里的主题色。

```
极简扁平信息插画，治愈系简笔画风格，圆润均匀的黑色细轮廓线，
低饱和度莫兰迪马卡龙配色，米白色做旧糙纸质感背景（#FDF8F0 满铺四边），
平面化设计，无复杂光影，整体画面干净柔和。
主强调色：{主题色，如 绿#4CAF50}（只用于核心元素，其余用低饱和马卡龙辅色）。
```

### ② 构图框架段（先定整体，再讲细节）

**A. 通用叙事构图（左右对比 / 流程 / 因果等）**

```
画面采用{左右对比分栏 / 从左到右流程 / 中心闭环循环 / 上下分层}结构，
{顶部/左侧/右侧/底部}各板块间用{黑色粗箭头 / 虚线连接 / 曲线路径}连接，
箭头方向表达「{文章逻辑，如：从混乱到收敛}」。
所有内容置于画面中央偏下，四周留白充足，底部 25% 高度留空（水印区，内容不得贴底）。
```

**B. 结构化功能卡片构图（适合「4 种入口 / 怎么选」）**

```
画面顶部居中一条黑色细标题横线，下方均匀排列 {2/3/4} 个等宽圆角矩形卡片，
卡片横向等距分布，各占约 {25/33/50}% 宽度，彼此用浅色虚线分隔。
每个卡片内部从上到下依次是：{编号圆形徽章}、{简笔图标}、{色块标签}、{3 个 bullet 小图标}、{底部小总结图标}。
卡片下方是「选择决策流」：一排小图标 + 箭头，指向最右侧/底部的推荐卡片。
底部 20% 高度留空（水印区），整体内容不贴边。
```

### ③ 左侧/上游板块段（问题 / 困境 / 旧模式 / 卡片 1-N）

**A. 通用叙事**

```
左侧{暖珊瑚粉 #FFD4D4}圆角矩形区域：
{具体场景描述，含简笔小白人状态 + 核心物件 + 环境细节}；
区域底部有{数量}个圆角{标签色}标签，用简笔图标替代文字表达
「{标签1含义}」「{标签2含义}」「{标签3含义}」。
```

**B. 功能卡片**

```
卡片 {n}（{配色，如 薄荷绿 #D4FFE0}）：
- 顶部圆形徽章内写数字「{n}」（用阿拉伯数字，仅允许数字）
- 徽章下方一个简笔图标，表达「{核心入口/工具/场景}」
- 图标下方一条{色块}标签带，用图形符号表达「{适用人群/场景}」
- 下方 3 个小图标横向排列，分别表达「{要点1}」「{要点2}」「{要点3}」
- 卡片底部一条细横线，左端小图标 + 右端小图标，表达「{使用结果/优势}」
```

### ④ 右侧/下游板块段（方案 / 结果 / 新模式 / 选择决策流）

**A. 通用叙事**

```
右侧{薄荷绿 #D4FFE0}圆角矩形区域：
{具体场景描述，含核心图形、循环结构、图标节点等}；
节点用{白色圆形+黑色轮廓}承载简笔图标，表达「{节点1}→{节点2}→{节点3}→{节点4}」的递进。
```

**B. 选择决策流（功能卡片专用）**

```
卡片矩阵下方有一行「怎么选？」决策带：
用 3-4 个连续小图标 + 黑色粗箭头串联，从左到右表达选择条件，
最终箭头指向最右侧的推荐卡片（该卡片边框加粗或加一个浅色高亮底）。
```

### ⑤ 收尾质感段（强调质感 + 版式整洁）

```
信息图排版，边缘清晰，手绘质感，高清画质，整洁有序，
所有元素风格完全一致（简笔图标、圆角矩形、黑色细轮廓线统一）。
```

### ⑥ 负面 Prompt（独立一段，稳定画风避坑）

```
写实，3D渲染，厚涂，厚重阴影，高饱和度刺眼色彩，杂乱背景，
人物写实五官，模糊扭曲，错别字，乱码，复杂纹理，多余装饰，
渐变效果，立体感，照片质感，真人形象，任何文字、字母、数字。
```

## 第三步：文字 → 图形 转换对照表（船长Talk 零文字铁律）

| 你想写的文字 | 转成什么图形 |
|-------------|-------------|
| 「目标太大」「系统太多」「没有收尾」 | 3 个圆角标签，各配一个简笔图标（超大地图/叠加方块/断尾箭头） |
| 「能开始→能上线」 | 4 节点闭环，每个节点一个图标（旗子/齿轮/对勾/火箭） |
| 「先做完整，再做复杂」 | 底部总结区：一个小完整方块 + 箭头指向 + 大复杂迷宫，迷宫画小 |
| 「缩小范围」 | 箭头上画一个内收的漏斗符号（不写字） |
| 「-4.7% vs -11.3%」 | 两根迷你柱状条，一矮一高，矮的绿色高的粉色 |
| 「70/30 样本外」 | 饼图切一块，大块蓝色小块粉色，不标数字 |
| 「正收益 / 负收益」 | 上升绿箭头 vs 下降红箭头（小图标） |
| 「适合初学者」 | 一个人形图标 + 小树苗/幼苗符号 |
| 「适合熟手」 | 一个人形图标 + 齿轮/闪电符号 |
| 「速度快」 | 小火箭或闪电图标 |
| 「托管/云端」 | 小云朵 + 齿轮图标 |
| 「4 种入口」 | 4 个编号圆形徽章（1/2/3/4），卡片顶部排列 |
| 「推荐选这个」 | 该卡片加粗边框或浅绿色高亮底，带一个对勾小图标 |

> 原则：图形能表达的关系，绝不写字。数字用比例/长短/大小暗示；阿拉伯数字仅允许出现在编号徽章内。

## 对照检查表（生成前过一遍）

- [ ] 一句话概念写了吗？（图要能「一句话讲清文章某段」）
- [ ] 关系类型选了吗？（对比/流程/比例/结构/因果/时间线/功能入口选择）
- [ ] 风格段放最前面，主题色标了吗？
- [ ] 构图框架段定了结构（左右对比/流程/闭环/分层/卡片矩阵）？
- [ ] 每个板块写了「画什么 + 代表文章什么」，不准只写画什么？
- [ ] 想写的文字全部转成图形了？（查对照表）
- [ ] 功能卡片：编号徽章用阿拉伯数字，其余位置无文字？
- [ ] 底部 20-25% 留空、四周不贴边？（否则裁切 FAIL）
- [ ] 负面词 6 项齐了吗？（写实/3D/厚涂/高饱和/乱码/文字）
- [ ] 生成后 crop_illustration_v7.py 四边 ≥3% 才可用，FAIL 就加 `--pad 200`，再不行 `--pad 400`

## 常见失败模式 & 对策

| 失败表现 | 根因 | 对策 |
|----------|------|------|
| 内容贴边、裁切 FAIL | 底部留空没写 | 补「底部 20-25% 高度留空」+ `--pad 200/400` |
| 图里出现中文/字母 | 负面词没写死 | 末尾必带「任何文字、字母、数字」 |
| 画成商业插画/写实风 | 风格段被挤到后面 | 风格段必须放最前面，负面词独立收尾 |
| 跟文章没关系 | 概念句没提炼 | 先写一句话概念，再填板块 |
| 主次不清 | 没标视觉核心 | 明确「XX 是全场最粗最深的元素」或「推荐卡片加粗边框」 |
| 颜色突兀 | 色板太自由 | 只给 1 主题色 + 低饱和马卡龙辅色，禁高饱和 |
| 元素风格不统一 | 元素语言不统一 | 全程用「简笔小白人/圆角矩形/简笔图标/编号徽章」固定词 |
| 卡片文字溢出/乱码 | bullets 用了文字描述 | 把 bullets 全改成图标，只保留数字编号 |

## 与 SOP §8.4.5 的关系

本模板是 §8.4.5 手绘科普风的操作化补充：§8.4.5 规定「风格铁律」，本模板规定「如何让图贴合文章内容」。两者缺一不可——只讲风格会得到精致但无关的图，只讲内容会得到贴题但粗糙的图。
